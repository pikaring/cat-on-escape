どんなゲーム

3びき そろえて、どうぐで まとめて。

そろった ねこは その場で消えるのではなく、ぎょうれつを つくって 画面の 右へ 走りぬけます。 4匹以上そろえると どうぐ が のこり、となりの ねこが 逃げると いっしょに はたらきます。

01

ねこの顔だけを ならべる

マスいっぱいに 顔を 大きく 出すので、小さい画面でも どの ねこか ひと目で わかります。

  • むずかしさで 4・5・6しゅるいを 切りかえ
  • 選んだ ねこは オレンジの わくで はっきり表示
02

4匹以上で どうぐが のこる

大きくそろえると、その場に どうぐが のこります（そのマスの猫は 消えて どうぐだけに なります）。 となりの ねこと 入れかえれば その場で はたらき、となりで ねこが 逃げても 巻きこまれて はたらきます。

  • ヨコに4匹 → ねこじゃらし（よこ一れつ）
  • タテに4匹 → ねこじゃらし（たて一れつ）
  • 5匹以上 → けいとだま（まわり3×3）
  • タテとヨコが交わる → すず（ななめクロス）
03

レベルと じゃまもの

逃がした猫がたまると レベルが 上がります。レベルが 上がるたび、いぬ や おおかみ が 盤に やってきます。

  • じゃまものは そろわず、動かせず、落ちてこない
  • その下には猫が 落ちないので、まわりから 回りこむ
  • となりで 猫が 逃げると 弱る。体力が 尽きれば 猫と 一緒に 逃げていく
  • むずかしさで 種類と じゃまものの 数が 変わる
04

おおきな文字・おおきなボタン

前作 Tap on NEKO と 同じ 見やすさの つくり。高コントラストで、押すところは すべて 48px 以上です。

  • ひらがな中心の わかち書き
  • ねこが「〜ニャ」と 今の ようすを 教えてくれます
05

やめどきが 自由

制限時間も ゲームオーバーも ありません。手が なくなったら ねこたちが 自動で ならびなおします。

  • 最高得点と 設定は この端末の中だけに 保存
  • いつ やめても、いつ 始めても だいじょうぶ

あそびかた

となりと いれかえるだけ。

1ねこを となりの マスへ ドラッグする（タップ2回でも いれかえられます）
2タテか ヨコに 同じ ねこが 3匹そろうと、走って 画面の 右へ 逃げていく
34匹以上そろえると どうぐが のこる。となりの ねこと 入れかえれば すぐ つかえる
4あいた ところに 上から 新しい ねこが 落ちてくる。そろえば そのまま 連鎖
5そろわない いれかえは 元に もどります（手数は ふえません）

パソコンでは マウスの ドラッグ、スマホ・タブレットでは 指で すべらせて あそべます。

つくり

HTML / CSS / JavaScript だけ。

フレームワークも ビルドも 使っていません。app/index.html を 開けば そのまま 動きます。 猫の絵は あとから 差しかえられるように、1か所に まとめてあります。

絵の 差しかえ口main.js の CAT_TYPES に 画像の パスを 書くだけ。読みこめない ときは 暫定の 丸のままで あそべます。
保存最高得点と 設定は LocalStorage に。サーバーには 何も 送りません。
画面サイズマスの 大きさは 画面に あわせて 自動計算。横向きでも スクロールなしで 収まります。
動きが 苦手な 方へprefers-reduced-motion に 対応。アニメーションを 切って あそべます。

よくある質問

気になるところ

お金は かかりますか？

かかりません。無料で、広告も 課金も ありません。

インストールは 必要ですか？

不要です。ブラウザで開くだけ。ホーム画面に追加すると、アプリのように 全画面で 開けます。

データは どこかに 送られますか？

送られません。最高得点も 設定も、お使いの端末の中だけに 保存されます。

じゃまものは どうすれば 消えますか？

いぬ・おおかみは 動かせません。となりの マスで 猫を 逃がすたびに 弱り、体力が 尽きると 猫たちと 一緒に 逃げていきます（いぬは2回、おおかみは3回）。どうぐの 一列消しを ぶつけるのが 手っとり早いです。

どうぐは どうやって 使いますか？

4匹以上そろえると、その場に どうぐが のこります（猫が どうぐに 変わります）。となりの ねこと 入れかえれば その場で つかえて、となりで ねこが 逃げた ときにも ひとりでに はたらきます。

猫は 何種類 いますか？

くろねこ・ちゃしろ・キジトラ・ハチワレ・みけねこ・しろねこの6種類です。「ねこの かず」から 4種類（やさしい）・5種類（ふつう）・6種類（むずかしい）を 切りかえられます。種類が多いほど そろいにくく なります。

前作との ちがいは？

Tap on NEKO は ねこの お世話と クイズ、こちらは パズルです。見た目と 操作の かんじは そろえてあります。
