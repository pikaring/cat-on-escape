# ストーリーモードの しくみ（分担と 受け渡しの 決まり）

「猫が消えた街　〜cat on escape〜」のストーリーモードを、**3つの担当が 同時に 作る**ための 決まりです。
ここに書いた形（ファイル・データ・関数）さえ守れば、ほかの担当の作業を待たずに進められます。

## 全体の 流れ

```
タイトル画面 ─┬─ ストーリー ─→ prologue → stage1 → [レベル1〜3] → clear1 → stage2 → [レベル4〜6] → clear2
              │                  → … → stage8 → [レベル22〜24] → clear8 → ending → タイトル画面
              └─ チャレンジ ─→ いまの ゲーム（むずかしさ3段階・レベルは どこまでも）
```

- **1面＝3レベル、全8面・24レベル**。面の はじめに `stageN`、3レベル目を クリアしたら `clearN` の ストーリーを はさむ。
- ストーリーを 読み終える（または スキップする）と、つぎの ゲームへ 進む。
- チャレンジモードは いまの ゲームの まま（保存キーも いまの まま）。

## 画面の 形（ストーリー画面）

```
┌────────────────────┐
│                    │
│   背景（全面）      │
│  ┌────┐   ┌────┐   │ ← 左右の 立ち絵（上半身）。セリフ窓の 上ふちに 立たせる
│  │ナオ│   │フミ│   │   話している 人は 明るく、だまっている 人は すこし 暗く
├──┴────┴───┴────┴───┤
│ ナオ                │ ← 名前
│ ここに いつも いる  │ ← セリフ（下半分）
│ 子が いない…        │
│              ▼ つぎ │
└────────────────────┘
```

- 画面の **下半分が セリフ窓**。上半分に 背景が 見え、左右に 立ち絵が 立つ。
- タップ（または Enter／スペース）で つぎへ。右上に「スキップ」。
- **画像が 読めない ときも 遊べる**こと（このリポジトリの 決まり）。
  背景が ない → 面ごとの 単色（下の表）。立ち絵が ない → 名前の 入った 丸い札。

## ファイルの 分担（ほかの 担当の ファイルは さわらない）

| 担当 | ファイル | 中身 |
| --- | --- | --- |
| ① 台本 | `app/story-data.js` | `window.STORY`（下の 形）。台本・登場人物・背景の 表 |
| ② ストーリー画面 | `app/story.js`、`app/story.css` | `window.StoryPlayer`（下の 形）。タイトル画面と ストーリー画面。DOM は JS で つくる |
| ③ ステージ構成 | `app/main.js`、`app/style.css` | モード切りかえ、ストーリーの 24レベル、保存、`StoryPlayer` の 呼び出し |

`app/index.html` の 読みこみ順は 土台で 決めてあるので、だれも 変えない：
`story.css` → `style.css`、`story-data.js` → `story.js` → `main.js`。

## ① `window.STORY` の 形

```js
window.STORY = {
  title: '猫が消えた街',
  subtitle: '〜cat on escape〜',

  // 登場人物。side は 立つ側（'left' | 'right'）。faces は 表情 → 画像の パス
  cast: {
    nao:  { name: 'ナオ', side: 'left',  faces: { normal: 'images/story/nao-normal.png', happy: '…', surprised: '…', serious: '…' } },
    fumi: { name: 'フミ', side: 'right', faces: { … } },
    tako1: { name: 'タコ一郎', side: 'right', faces: { normal: 'images/story/tako1-normal.png', down: '…' } },
    // … tako2〜tako7, daiou, momo
  },

  // 背景。image が 読めない ときは color
  backgrounds: {
    road: { image: 'images/story/bg-road.png', color: '#a8d4e6' },
    // … 上の 表の すべて
  },

  // 8つの 面（main.js が 面の 名前や ボスの 表示に つかう）
  stages: [
    { name: 'いつもの 通学路', bg: 'road', boss: 'tako1' },
    // … 8つ
  ],

  // 場面。キーは prologue, stage1〜stage8, clear1〜clear8, ending
  scenes: {
    prologue: [ /* ステップの ならび */ ],
    stage1: [ … ],
    clear1: [ … ],
    // …
    ending: [ … ],
  },
};
```

### ステップ（場面の 1コマ）

1コマ ＝ タップ1回。すべての キーは 省略できる。書いた ものだけ 変わり、書かない ものは まえの コマの まま。

```js
{ bg: 'road' }                                   // 背景を かえる（text が なければ すぐ つぎへ）
{ left: 'nao', right: 'fumi' }                   // 立ち絵を 置く。null で 消す
{ who: 'nao', face: 'surprised', text: 'いない…' } // 話す。who の 立ち絵が 明るくなり、表情が かわる
{ who: 'fumi', text: 'マジ？' }                   // face を 書かなければ 表情は まえの まま（はじめは normal）
{ text: 'つぎの 朝、ふたりは…' }                  // 地の文（名前なし）
{ right: 'tako1', who: 'tako1', text: 'ネコは いただいたタコ！' } // まとめて 書いても よい
{ bg: 'ending', picture: true }                   // 絵だけを 見せる（セリフ窓と 立ち絵を かくして タップを まつ）
```

- `cast` の 人に `height`（0〜1、既定 1）を 書くと、その わりあいの 高さに 立つ（絵の 下を 窓の うしろへ しずめる）。
  背の ちがいは これで 出す（ナオ 0.8・フミ 1・大王 1）。`size`（既定 1）は 絵の 大きさ（タコ一郎〜七郎 0.75、モモ 0.55）。
- `left` / `right` には `cast` の キー。`'nao:happy'` のように `:表情` を つけても よい。
- `who` が 左右の どちらにも いない ときは、名前だけ 出して 立ち絵は かえない。
- `text` の 改行は `\n`。1コマ **3行・60文字まで**（スマホで あふれない）。
- ひらがなを 多めに、文節で 半角スペースを 入れる（ゲームの ほかの 文と そろえる）。

## ② `window.StoryPlayer` の 形

```js
// タイトル画面を 出す。ボタンが 押されたら 画面を 閉じてから コールバックを よぶ
StoryPlayer.showTitle({
  storyNote: '3面 レベル2 から',   // ストーリーの ボタンの 下に 出す（はじめてなら 'はじめから'）
  onStory() {},
  onChallenge() {},
});

// 場面を 再生する。読み終える（または スキップ）と 画面を 閉じて onDone を よぶ
StoryPlayer.play('stage1', () => {});

// その 場面が ある か（台本が まだ ない ときの ため）
StoryPlayer.has('clear3');   // → true / false
```

- `window.STORY` が ない、または 場面が ない ときは、`play` は すぐ `onDone` を よぶ（ゲームが 止まらない）。
- 画面は `position: fixed` の 全面。ゲームの 画面の 上に かぶせる（`z-index` は 100 より上）。
- `showTitle` の 画面には「ストーリー」「チャレンジ」の 大きな ボタン 2つ（48px 以上、前作の 見た目）。

## ③ `main.js` が やること

- 起動したら `StoryPlayer.showTitle(…)` を よぶ。`StoryPlayer` が ない ときは 今までどおり チャレンジで 始める。
- ストーリー：レベル `n`（1〜24）の 面は `Math.ceil(n / 3)`。
  - 面の 1レベル目を 始める まえに `play('stageN')`、3レベル目を クリアしたら `play('clearN')`。
  - はじめての ときは `stage1` の まえに `play('prologue')`。24レベル目の あとは `clear8` → `ending` → タイトルへ。
  - 保存キーは `catonescape.story`（`{ level, stars, board }`）。チャレンジの 保存とは 分ける。
  - むずかしさは 面が 進むほど 上がる（ねこの 種類・めあて・じゃまもの）。むずかしさボタンは ストーリーでは 出さない。
- 下の ボタンに「タイトル」へ もどる 道を 用意する。
