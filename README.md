# cat-on-escape（ねこを にがせ / Cat on Escape）

ねこの顔をスライドして、タテかヨコに **3匹** そろえる落ちものパズルです。
そろった猫は行列をつくって **画面の右へ走って逃げていきます**。猫を逃がすのが目的のゲームです。
**4匹以上**そろえると、その場に「どうぐ」（ねこじゃらし・けいとだま・すず）が残り、まとめて逃がせます。

バックエンドなし（HTML / CSS / Vanilla JavaScript のみ）。最高得点と設定は LocalStorage に保存します。
見た目と操作感は前作 [tap-on-neko（ねこの ともだち）](https://github.com/pikaring/tap-on-neko) に合わせてあります。

**紹介ページ → https://pikaring.github.io/cat-on-escape/**
**あそぶ → https://pikaring.github.io/cat-on-escape/app/**

## 遊びかた

- 隣り合う猫をドラッグ、またはタップ2回で入れかえます。
- タテかヨコに同じ猫が **3匹** そろうと、猫たちが画面の右へ走って逃げます。
- **4匹以上**そろえると、その場に「どうぐ」が残ります。**そのマスの猫は消えて、どうぐだけ**になります（猫としてはそろわなくなります）。

| そろえかた | 手に入るどうぐ | はたらき |
| --- | --- | --- |
| ヨコに4匹 | ねこじゃらし（よこ） | よこ一列を逃がす |
| タテに4匹 | ねこじゃらし（たて） | たて一列を逃がす |
| 5匹以上 | けいとだま | まわり3×3を逃がす |
| タテとヨコが交わる（L字・T字） | すず | ななめクロスを逃がす |

- どうぐの使いかたは2通りです。
  - **となりの猫と入れかえる** → その場ではたらきます（そろえる必要はありません）
  - **となりで猫が逃げる** → 巻きこまれて一緒にはたらきます
- どうぐが別のどうぐを巻き込むと連鎖します。盤にどうぐが残っているあいだは手づまりになりません。
- 空いたマスには上から新しい猫が降ってきます。落ちてきた猫がまたそろうと連鎖になり、得点が倍々になります。
- そろわない入れかえは元に戻ります（手数は増えません）。
- 入れかえる手がなくなったら、猫たちが自動で並びなおします。
- 制限時間はありません。

### レベル（ステージ）と ひと区切り

- 1レベルは **15手**。そのあいだに **めあての数** だけ猫を逃がせばクリアです。ヘッダーのバーが進み具合、「のこり ○て」が残りの手数です。
- クリアすると ★1〜3（残った手が15手の4割以上で★3、2割以上で★2）と、残り手数ボーナス（1手50点）がもらえます。
- クリアのたびに **「つぎの レベルへ」／「きょうは ここまで」** を選べます。「きょうは ここまで」で盤が止まり、つぎに遊ぶレベルが表示されます。
- 手がなくなったら「もういちど」で同じレベルをやりなおせます。「やりなおす」ボタンでも いつでも最初からやりなおせます。
- 進んだレベルと★は **むずかしさごとに** 保存され、次に開くと続きのレベルから始まります。「むずかしさ」の画面の「レベル 1 から あそぶ」で最初に戻れます。
- めあての数は `むずかしさの rate × 15手 × きつさ`。きつさはレベル1の0.45から1レベルごとに0.03上がり、レベル20で1.0（適当に打つと半分くらい届かない）で止まります。
- 数値はシミュレーション（ランダムに打つ／一番長くそろう手を打つ の2通り）で合わせてあります。

### じゃまもの

- レベルが進むと、ステージの始めから **じゃまもの（いぬ・おおかみ）** が盤にいます（むずかしさごとの上限まで）。
- じゃまものは **猫ではないのでそろわず、動かせず、落ちてきません**。その下には猫が落ちてこないので、まわりから回り込んで埋まります。
- マスの色が赤いので、猫のマスとひと目で見分けられます。
- **となりで猫が逃げると弱ります**（いぬは2回、おおかみは3回）。体力が尽きると猫たちと一緒に逃げていきます。

### むずかしさ

| むずかしさ | 猫の種類 | めあて（レベル1 → 20〜） | じゃまもの |
| --- | --- | --- | --- |
| やさしい | 4種類 | 80 → 180匹 | なし |
| ふつう | 5種類 | 45 → 105匹 | レベル3から1匹、3レベルごとに+1（最大2）。レベル8からおおかみも |
| むずかしい | 6種類 | 35 → 75匹 | レベル2から1匹、2レベルごとに+1（最大3）。レベル4からおおかみも |

猫の種類が少ないほど連鎖が起きやすく、1手で逃げる数が多いので、めあても大きくなります。

得点は `（逃げた数 × 10 ＋ どうぐ 50 ＋ おいはらった じゃまもの 100）× 連鎖数`、クリア時に残り手数ボーナスが加わります。
スコアはレベルごとに0から数え、「さいこう」は1レベルでの最高得点です。
保存キーは `catonescape.best`（最高得点）・`catonescape.diff`（むずかしさ）・`catonescape.progress`（むずかしさごとの到達レベルと★）。

## 猫の絵の差し替え

5種類とも差し替えずみです（Gemini で生成 → `tools/make_face.py` で背景除去・512px化）。
描き直すときも手順は同じです。

1. 生成した画像を `tools/make_face.py` に通す（背景除去・切り出し・正方形・512px化）。
   5匹を1枚のグリッドで作らせると画風がそろいます。切り分けは自動です。
   ```
   pip install pillow numpy
   # 3列×2行のグリッド1枚を、左上から右へ の順に5枚へ切り分ける
   python3 tools/make_face.py app/images grid.jpg:face-kuro,face-chashiro,face-kijitora,face-hachiware,face-mike
   # 1匹ずつの画像でも これまでどおり
   python3 tools/make_face.py app/images chashiro.jpg:face-chashiro
   ```
2. `app/main.js` 冒頭の `CAT_TYPES` の `image` にパスを書く。

```js
const CAT_TYPES = [
  { key: 'kuro',      name: 'くろねこ', image: 'images/face-kuro.png' },
  { key: 'chashiro',  name: 'ちゃしろ', image: 'images/face-chashiro.png' },
  { key: 'kijitora',  name: 'キジトラ', image: 'images/face-kijitora.png' },
  { key: 'hachiware', name: 'ハチワレ', image: 'images/face-hachiware.png' },
  { key: 'mike',      name: 'みけねこ', image: 'images/face-mike.png' },
];
```

- 画像は読み込みに成功したときだけ使われます。パスを間違えても、その種類だけ暫定の丸で遊べます。
- 1種類ずつ順に差し替えても崩れません。
- 3×3のスプライトシート（前作と同じ形式）を使うときは `sheet: true` を足すと左上のコマだけを表示します。
- どうぐの絵も同じ要領で、`ITEMS` の `image` にパスを書けば絵文字から差し替わります。
- 画像生成AI（Gemini）用のプロンプトは `docs/asset-prompts.md` にあります。5匹の画風をそろえる手順つき。

## 調整できるところ

`app/main.js` の冒頭にまとまっています。

| 定数 | 既定値 | 意味 |
| --- | --- | --- |
| `COLS` / `ROWS` | 7 / 8 | 盤面の列数・行数 |
| `MIN_MATCH` | 3 | 何匹そろったら逃げるか |
| `ITEM_MIN` | 4 | 何匹そろったら どうぐが残るか |
| `ITEM_TRIGGER` | `'adjacent'` | どうぐが働くきっかけ。`'adjacent'`＝となりの猫が逃げたら／`'included'`＝どうぐ自身がそろったら |
| `MOVES` | 15 | 1レベルの手数 |
| `GOAL_START` / `GOAL_STEP` / `GOAL_TOP` | 0.45 / 0.03 / 1.0 | めあての きつさ（レベル1／1レベルごとの増加／上限） |
| `STAR2` / `STAR3` | 0.2 / 0.4 | ★2・★3になる残り手数の割合 |
| `MOVE_BONUS` | 50 | クリア時の残り1手あたりのボーナス |
| `BLOCKERS` | いぬ hp2 / おおかみ hp3 | じゃまものの体力と見た目 |
| `DIFFS` | やさしい／ふつう／むずかしい | 猫の種類数・`rate`（1手で逃げる数のめやす）・じゃまものの上限と出はじめ・おおかみが出るレベル |
| `SWAP_MS` / `FALL_MS` | 170 / 260 | 入れかえ・落下のアニメ時間（ms） |
| `RUN_MS` / `RUN_STAGGER` / `ESCAPE_HOLD` | 900 / 55 / 230 | 右へ走る時間・行列のずれ・盤を詰めはじめるまで（ms） |

`SWAP_MS` / `FALL_MS` / `RUN_MS` は `app/style.css` の `--swap-ms` / `--fall-ms` / `--run-ms` と対になっているので、変えるときは両方そろえてください。

## 紹介ページの 本・グッズ（Amazonアソシエイト）

`index.html` の `<div class="good" data-asin="...">` が商品カードです。ほかのサイト
（reach-on-sanma など）と同じ形式で、リンクは `https://www.amazon.co.jp/dp/ASIN?tag=redcomet-22`。

画像と価格は `assets/goods.json` から後付けで差し込みます（無ければテキストのまま表示）。
生成は `tools/fetch_goods.py`、毎日の更新は `.github/workflows/goods.yml` が担当します。

動かすには、リポジトリの Settings → Secrets and variables → Actions に
`CREATORS_CLIENT_ID` と `CREATORS_CLIENT_SECRET` を登録してください。
登録するまでのあいだ、ワークフローは失敗せずに何もしません（画像と価格が出ないだけで、
アフィリエイトのリンク自体は Secret と関係なく動きます）。
